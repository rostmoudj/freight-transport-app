# Freight Transport Application

## Overview
The Freight Transport Application is a comprehensive web application designed to manage the operations of a freight transport company. It provides functionalities for managing shipments, vehicles, drivers, and generating reports, all while ensuring a responsive design that works seamlessly on both mobile and desktop devices.

## Features
- **User Authentication**: Secure login for users with role-based access.
- **Dashboard**: Displays key statistics and charts for quick insights into operations.
- **Shipments Management**: Create, edit, and view shipments with filtering and pagination.
- **Vehicle Management**: Manage vehicle details, statuses, and performance metrics.
- **Driver Management**: Track driver information and performance.
- **Reports Generation**: Generate and export reports for analysis.

## Technologies Used
- **Frontend**: React, TypeScript, CSS
- **Backend**: RESTful API (to be implemented)
- **Build Tool**: Vite

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd freight-transport-app
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```

## Usage
- Access the application in your browser at `http://localhost:3000`.
- Use the login page to authenticate and access the dashboard and other features.
